# website-Perpustakaan
# Sistem Informasi Perpustakaan Berbasis Web


Project ini merupakan aplikasi web CRUD+ berbasis Django yang digunakan untuk mengelola data perpustakaan secara digital. Sistem memiliki fitur autentikasi login, dashboard analitik, manajemen buku, manajemen anggota, peminjaman, serta pengembalian buku. Website ini dibuat untuk mempermudah proses pengelolaan perpustakaan agar lebih efektif dan terstruktur dengan menggunakan database MySQL dan framework Django.
